Text Field Textarea

여러 줄의 긴 글을 입력받고 높이를 자동으로 맞추는 칸입니다.

Preview

Usage

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

Properties

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
켜고 끄는 속성variant size

CSS Variables

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-textarea-paddingvar(--ybm-space-x3_5) var(--ybm-space-x4)
--ds-textarea-min-height94px
--ds-textarea-radiusvar(--ybm-shape-lg)
--ds-textarea-font-sizevar(--ybm-font-size-t05)
--ds-textarea-line-heightvar(--ybm-line-height-t05)
--ds-textarea-linevar(--ybm-color-stroke-neutral-weak)
--ds-textarea-line-width1px

Specification

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

variant : outline(기본) / underline      size : large(기본) / medium
Figma outline large : px16 / py14 / min-h94 / shape/lg / t05
      outline medium: px14 / py12 / min-h82 / shape/sm / t04
      underline large : py8+14 / min-h110 / t06 / 하단 1px / underline medium: py6+12 / min-h94 / t05
focused 1px stroke/neutral-contrast / invalid 1px stroke/critical-solid / disabled/readOnly bg/disabled
