Skeleton

콘텐츠가 불러와지는 동안 그 구조를 미리 보여 주는 자리 표시입니다.

Preview

Usage

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

Properties

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
shaperect circle text

CSS Variables

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-skeleton-colorvar(--ybm-color-palette-gray-200)
--ds-skeleton-size48px

Guidelines

  • 목록, 카드처럼 반복되는 데이터 화면처럼 곧 나타날 구조를 미리 보여 줄 수 있는 곳에 씁니다.
  • 모서리는 대체하려는 콘텐츠에 맞춥니다.
  • Progress Circle 과 같이 쓰지 않습니다. 같은 로딩을 두 번 알리는 셈입니다.
  • 구조를 미리 보여 줄 수 있는 1~10초 로딩은 Skeleton, 로딩 중이라는 사실만 알리는 1~4초는 Progress Circle 입니다.

Specification

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

shape: rectangle(기본) / circle / text
Figma: palette/gray-200 / rectangle shape/sm / circle pill / text 줄 높이 14 / 줄 사이 x2 / 마지막 줄 64%
