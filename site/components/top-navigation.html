사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
stateenabled hover
켜고 끄는 속성search action

그 밖에: Item selected

사용 지침

  • PC 전용. 메뉴는 7개까지, 지금 화면이 속한 메뉴에 aria-current="page". 화면이 좁아지면 Top App Bar 와 메뉴 버튼으로 바꾼다.

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

Figma: padding x2 / bg/layer-default / 왼쪽 묶음 gap x4 / 메뉴 사이 x1 / 오른쪽 끝 버튼 사이 x1
  로고 칸 높이 x8, 좌우 padding x2, 로고 높이 28
  Top Navigation Item 높이 x8, 좌우 padding x3, shape/sm, t04 Medium fg/neutral-muted
