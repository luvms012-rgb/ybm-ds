Bottom Sheet

화면 아래에서 올라오는 창입니다. 지금 화면을 유지한 채 추가 정보나 동작 목록을 보여 줍니다.

Preview

정렬

Usage

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

Properties

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
header-aligncenter

Guidelines

  • 동작 몇 개 중 하나를 고를 때는 Menu Sheet, 입력이나 긴 내용은 Bottom Sheet. 되돌릴 수 없는 동작은 critical 로 따로 묶는다.
  • PC 에서 화면 옆에 보조 내용이나 필터를 둘 때 Side Panel, 화면이 좁으면 Bottom Sheet 로 바꾼다.

Specification

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

headerAlign: left(기본) / center   handle: data-handle
Figma: 폭 채움 / 위쪽 shape/3xl / bg/layer-floating
  header 24/20/16/20 / gap x2 / title t07 SemiBold / desc t05 fg/neutral-muted
  body 12/20/16/20 / min-h64 / footer 16/20/24/20 / 닫기 40×40(위 18 / 오른쪽 10) / handle 36×4 palette/gray-400 (위 6)
