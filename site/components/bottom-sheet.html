정렬

목록을 어떤 순서로 볼지 골라 주세요.

부품설명
Header ds-bottomsheet__header제목과 닫기 버튼이 놓이는 머리 영역입니다.

Footer ds-bottomsheet__footer버튼이나 보조 정보가 놓이는 아래 영역입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
header-aligncenter

사용 지침

구분내용
Do몇 가지 동작 중 하나를 고를 때는 Menu Sheet를 씁니다.
Do입력이나 긴 내용은 Bottom Sheet에 담습니다.
Do되돌릴 수 없는 동작은 critical로 따로 묶습니다.
DoPC 화면 옆에 보조 내용이나 필터를 둘 때 Side Panel을 씁니다.
Do화면이 좁으면 Bottom Sheet로 바꿉니다.

정렬

직접 입력할 수도 있는 선택 받기

고르다가 직접 적어야 할 수도 있는 값은 Field Button으로 Bottom Sheet를 열어 받습니다. 동작 몇 개 중 하나를 고를 때만 Menu Sheet를 쓰고, 입력이 있으면 Bottom Sheet를 씁니다.

배송 요청 사항

짧은 안내는 제목을 가운데로
