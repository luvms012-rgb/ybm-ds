사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
켜고 끄는 속성tone

바꿀 수 있는 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-slider-value50%
--ds-slider-activevar(--ybm-color-bg-neutral-solid)
--ds-slider-thumb-linevar(--ybm-color-bg-neutral-solid)

사용 지침

  • 터치 대상은 썸이 아니라 썸과 트랙 전체입니다. 트랙을 누르면 그 위치로 바로 이동합니다.
  • 연속형은 부드럽게, 이산형은 정해진 단위로 가장 가까운 단계에 맞춥니다.
  • 알맞은 기본값을 미리 넣어 사용자의 수고와 실수를 줄입니다.
  • 조작 중에는 현재 값을 표시합니다.

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

tone: neutral(기본) / brand
채움 길이는 --ds-slider-value(0~100%) — ybm-ds.js 가 input 마다 자동으로 갱신한다.
Figma: 높이 20 / 트랙 4 pill palette/gray-200 / 채움 bg/neutral-solid(brand bg/brand-solid)
       썸 20 static-white + 1px 테두리(채움 색) + elevation raised
       disabled opacity .7 / 채움 bg/disabled / 썸 테두리 stroke/neutral-weak
