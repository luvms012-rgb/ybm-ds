Field Button

직접 타이핑하지 않고 눌러서 값을 고르는 입력 필드입니다. 날짜, 시간, 선택지처럼 별도 화면이나 시트를 띄워 값을 받는 자리에 씁니다.

FigmaCSS

미리보기

사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
sizelarge medium

그 밖에: 상태 enabled/disabled/readOnly/invalid

사용 지침

  • 폼 제출이 필요하면 disabled 대신 readOnly.
  • 폼을 제출해야 하는 필드는 disabled 대신 readOnly 를 쓰세요. disabled 값은 제출되지 않습니다.
  • 사용자가 자유롭게 입력해야 하면 Field Button 이 아니라 Text Field Input 입니다.
  • 라벨, 설명, 오류 문구는 이 컴포넌트에 없습니다. Field Label 로 감싸세요.
  • 전체 삭제(clear) 버튼은 suffix 와 역할이 겹쳐 넣지 않습니다.

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

Figma large : h52 / px16 / gap10 / shape/lg / t05 / icon 20 / medium: h40 / px14 / gap8 / shape/sm / t04 / icon 16
       1px stroke/neutral-weak / invalid 1px stroke/critical-solid / disabled/readOnly bg/disabled
       affix/아이콘 fg/neutral-subtle / placeholder fg/placeholder / 값 fg/neutral
readOnly: aria-readonly="true" (폼 제출이 필요하면 disabled 대신 readOnly — DS §6.4)
