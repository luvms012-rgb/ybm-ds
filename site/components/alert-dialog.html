Alert Dialog

하던 일을 잠시 멈추고 중요한 확인을 받는 창입니다.

Figma코드
새 창으로 열기
전체 목차 llms.txt

사진을 삭제할까요?

삭제하면 되돌릴 수 없어요.

사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

구조

주문을 취소할까요?

취소한 주문은 되돌릴 수 없습니다.

부품설명
Header ds-alertdialog__header제목과 닫기 버튼이 놓이는 머리 영역입니다.
Title ds-alertdialog__title제목입니다.
Desc ds-alertdialog__desc제목에 덧붙이는 설명 글입니다.
Footer ds-alertdialog__footer버튼이나 보조 정보가 놓이는 아래 영역입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
actionpair critical nonpreferred

그 밖에: 272 폭

사용 지침

구분내용
Do되돌릴 수 없는 작업을 확인받을 때 씁니다.
Do바깥을 눌러도 닫히지 않고 버튼으로만 닫힙니다.

예시

지우기 전에 한 번 더 묻기

되돌릴 수 없는 삭제는 Alert Dialog로 확인받고, 실행 버튼은 criticalSolid로 둡니다. 바깥을 눌러도 닫히지 않아 버튼을 골라야만 넘어갑니다.

  • 회사 서울시 중구 한빛로 12, 3층

배송지를 삭제할까요?

삭제한 배송지는 되돌릴 수 없어요.

쓰던 글을 두고 나갈 때 묻기

쓰던 내용이 사라지는 동작 앞에서 한 번 더 묻고, 두 버튼을 가로로(pair) 나란히 둡니다. 확인 버튼에는 "나가기"처럼 실제로 일어나는 일을 적습니다.

후기 쓰기

후기 쓰기를 그만둘까요?

지금 나가면 쓴 내용이 사라져요.

버튼 글이 길면 위아래로 쌓기

버튼 글이 길어 가로 두 칸에 들어가지 않으면 stacked로 위아래로 쌓습니다. 해지처럼 잃는 것이 있는 동작은 설명에 무엇이 사라지는지 적습니다.

  • 멤버십 다음 결제일 12월 1일 월 4,900원

멤버십을 해지할까요?

해지하면 남은 쿠폰 2장과 무료 배송 혜택이 사라져요.
