사용법

아래 구조를 그대로 복사해 쓰세요. 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
cell statetoday selected range-start range-middle range-end

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

--ds-date-pill-linetransparent
--ds-date-tracktransparent

사용 지침

구분내용
Do날짜 고르기가 화면의 주된 일이거나 단계별 흐름의 한 단계면 화면에 바로 둡니다. 폼의 입력 칸을 눌러 고를 때는 Bottom Sheet 안에 넣습니다.
Do여는 버튼은 Select Trigger, Text Field Input, Field Button 중 하나를 씁니다.
Do처음에는 오늘이 있는 달을 보여 주고, 이미 고른 날짜가 있으면 그 달을 보여 줍니다.
Do기간의 최소, 최대 조건은 Callout으로 미리 알려 줍니다. 시작일만 고른 상태에서는 확인 버튼을 끕니다.
Do오늘이 선택된 날짜이기도 하면 선택 모양을 먼저 보여 줍니다.

selection: single / range
Figma: 폭 320 / padding x5 / gap x3 / shape/2xl / bg/layer-default / elevation overlay(+헤어라인)
  header h40 / 이동 버튼 24 폭 / chevron 24 fg/neutral / title t06 Bold 가운데
  요일 t04 fg/neutral-subtle / 셀 40×44 / pill 32×32 shape/xl / label t05
  today pill 1px stroke/brand-solid + fg/brand Medium / selected pill bg/brand-solid + fg/on-brand-solid Medium
  range 띠 bg/brand-weak 32 높이 (start 오른쪽 절반 / end 왼쪽 절반 / middle 전체, middle 글자 fg/brand) / disabled fg/disabled
