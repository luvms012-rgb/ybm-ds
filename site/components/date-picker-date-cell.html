사용 지침

구분내용
Do날짜 고르기가 화면의 주된 일이거나 흐름의 한 단계면 화면에 바로 둡니다. 폼의 입력 칸을 눌러 고를 때는 Bottom Sheet 안에 넣습니다.
Do여는 버튼은 Select Trigger, Text Field Input, Field Button 중 하나를 씁니다.
Do처음에는 오늘이 든 달을 보여 줍니다. 이미 고른 날짜가 있으면 그 달을 보여 줍니다.
Do기간의 최소, 최대 조건은 Callout으로 미리 알려 줍니다. 시작일만 고른 상태에서는 확인 버튼을 끕니다.
Do오늘을 고른 경우에는 오늘 표시보다 선택 모양을 먼저 보여 줍니다.

예시

흐름의 한 단계로 화면에 바로 두기

날짜 고르기가 신청 흐름의 한 단계일 때는 달력을 화면에 바로 둡니다. 처음에는 오늘이 든 달을 보여 주고, 고를 수 없는 지난 날짜는 disabled로 막습니다.

입력 칸을 눌러 Bottom Sheet에서 고르기

폼의 날짜 칸은 Field Button으로 만들고, 누르면 Bottom Sheet 안의 달력에서 고릅니다. 오늘을 고른 경우에는 오늘 표시 대신 선택 모양만 보여 줍니다.
