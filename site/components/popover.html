Popover

누른 요소 옆에 작은 창을 띄워 부가 정보나 작업을 보여 주는 컴포넌트입니다.

Figma코드
새 창으로 열기
전체 목차 llms.txt
링크 공유

링크가 있는 사람만 볼 수 있어요

사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

구조

제목

설명

본문
부품설명
Headerds-popover__header제목과 닫기 버튼이 놓이는 머리 영역입니다.
Textsds-popover__texts제목과 설명을 묶는 글자 영역입니다.
Titleds-popover__title제목입니다.
Descds-popover__desc제목에 덧붙이는 설명 글입니다.
Closeds-popover__close닫기 버튼입니다.
Bodyds-popover__body본문이 들어가는 영역입니다.
Footerds-popover__footer버튼이나 보조 정보가 놓이는 아래 영역입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
actionssingle pair none

그 밖에: 폭 320

동작

ybm-ds.js를 불러오면 알아서 동작합니다.

  • data-ds-popover="id" 로 열고 닫기, 바깥 클릭과 Esc, 안의 data-ds-close 로 닫기

사용 지침

구분내용
DoPopover는 버튼 옆에 뜨는 작은 창이고, 바깥을 누르면 닫힙니다.
Do화면을 막고 확인받아야 할 때는 Dialog를 씁니다.

예시

버튼 옆에서 끝나는 작은 작업 열기

공유처럼 버튼 옆에서 끝나는 작은 작업은 Popover로 엽니다. 바깥을 누르면 닫히므로 화면을 막고 꼭 확인받아야 할 때는 Dialog를 씁니다.

닫기 버튼 대신 아래 버튼으로 닫기

필터처럼 고른 뒤 적용하는 작업은 아래에 취소와 적용 버튼을 두고 위쪽 닫기 버튼은 뺍니다. 닫기 버튼을 빼면 아래 버튼에 data-ds-close를 붙여 창이 꼭 닫히게 합니다.

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-popover-width320px
--ds-popover-gapvar(--ds-space-x2)

크기와 여백

actions: single / pair / none(footer 없음)   placement: bottom-start(기본) / bottom-end / top-start / top-end
ybm-ds.js: data-ds-popover 로 열고 닫기, 바깥 클릭과 Esc 로 닫기, 안의 data-ds-close 로 닫기.
Figma: 폭 320 / padding x5 / gap x4 / shape/xl / bg/layer-floating / 1px stroke/neutral-muted / elevation 2
  title t05 Bold fg/neutral / desc t04 fg/neutral-subtle / 글 사이 x1 / 머리말 gap x3 / 닫기 Lucide/x 20 fg/neutral
  body t04 fg/neutral / footer 오른쪽 정렬 gap x2, Action Button small
닫기 버튼을 숨기면 본문이나 버튼 영역에 닫는 동작을 꼭 둔다.
