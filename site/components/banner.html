Banner

화면 맨 위에서 서비스 전체 공지를 알려 주는 컴포넌트입니다.

Figma코드
새 창으로 열기
전체 목차 llms.txt

안내 개인정보 처리방침이 12월 1일부터 바뀌어요.

자세히

사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

구조

점검 안내 10월 25일(토) 02:00~06:00 서비스를 점검해요.

자세히
부품설명
Inner ds-banner__inner배너 내용을 가운데에 정해진 폭으로 담는 영역입니다.
Message ds-banner__message알릴 내용을 담은 글입니다.
Title ds-banner__title제목입니다.
Action ds-banner__action바로 실행하는 작은 버튼입니다.
Close ds-banner__close닫기 버튼입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

그 밖에: tone neutral, informative, positive, warning, critical, variant solid

사용 지침

구분내용
DoBanner는 화면 맨 위에 전체 폭으로, 한 번에 하나만 띄웁니다.
Do본문 안의 안내는 Callout을 씁니다.

예시

점검 일정을 화면 맨 위에 알리기

모든 화면에 걸리는 점검 공지는 Banner로 화면 맨 위에 전체 폭으로 띄웁니다. 한 번에 하나만 두고, 자세한 내용은 오른쪽 링크로 넘깁니다.

점검 안내 9일 새벽 2~6시에 점검해요.

자세히

홈

  • 주문 내역 최근 3개월 2건
  • 쿠폰함 쓸 수 있는 쿠폰 3장

급한 장애는 바로 읽히게 알리기

결제 장애처럼 바로 알아야 하는 공지는 critical 톤과 role="alert"로 띄웁니다. 문구에는 지금 쓸 수 있는 다른 방법까지 적습니다.

결제 장애 일부 카드 결제가 되지 않아요. 계좌 이체나 간편 결제를 써 주세요.

서비스 이름
홈 쇼핑 주문 내역 고객센터
로그인

한 번 읽으면 되는 공지는 닫을 수 있게

정책 변경처럼 한 번 읽으면 되는 공지에는 닫기 버튼을 붙여 사용자가 치울 수 있게 합니다. 닫기 버튼의 aria-label에는 무엇을 닫는지 적습니다.

규격

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-banner-bgvar(--ds-color-bg-neutral)
--ds-banner-fgvar(--ds-color-fg-neutral)
--ds-banner-max1200px

크기와 여백

tone: neutral(기본) / informative / positive / warning / critical   variant: weak(기본) / solid
Figma: 전체 폭 / 모서리 없음 / min-h48 / padding x3 x4 / 내용 최대 폭 --ds-banner-max(1200) 가운데 / gap x2
  t04 / 제목 Bold / 아이콘 Solid 16 / action t04 Bold 밑줄 / 닫기 20(터치 영역 40)
  weak: Callout 과 같은 tone 색 / 아래 1px stroke/neutral-weak
  solid: bg/{tone}-solid + fg/on-{tone}-solid (neutral = bg/neutral-solid + fg/on-neutral-solid)
Callout 과 차이: Callout 은 본문 안 안내(둥근 상자), Banner 는 페이지 전체에 걸린 공지(화면 맨 위, 한 번에 1개).
