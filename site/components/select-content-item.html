Select Content · Item

Select 를 열었을 때 나오는 목록 창과 그 안의 한 줄입니다.

미리보기

사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

바꿀 수 있는 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-select-item-paddingvar(--ybm-space-x3) var(--ybm-space-x2)
--ds-select-item-gapvar(--ybm-space-x3)
--ds-select-item-check20px

사용 지침

  • Item Label 은 명사형으로 짧고 명확하게 씁니다. 동작이나 부연 설명을 라벨에 함께 적지 않습니다.
  • Trigger 너비에서 말줄임되지 않는지 확인하세요.
  • 옵션 순서는 하나의 기준(사용 빈도, 크기, 시간)으로 일관되게 정렬합니다. 성격이 다르면 그룹으로 분리하세요.
  • "전체 선택", "없음"처럼 다른 옵션의 상태를 바꾸는 옵션은 넣지 않습니다. 다만 "없음"이 정답이 될 수 있는 단일 선택 필드에는 "없음" 옵션을 목록에 포함합니다.
  • 값 고르기는 Select, 동작 실행은 Menu 입니다.
