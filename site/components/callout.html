Callout

본문 안에서 꼭 알아야 할 정보를 눈에 띄게 알려 주는 컴포넌트입니다.

Figma코드
새 창으로 열기
전체 목차 llms.txt

주문하신 상품은 내일 출발해요. 배송 조회

사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

구조

점검 예정 11월 8일 오전 2시부터 4시까지 결제를 할 수 없어요. 자세히 보기

부품설명
Content ds-callout__content주된 내용이 들어가는 영역입니다.
Title ds-callout__title제목입니다.
Link ds-callout__link자세히 보기 같은 이동 링크입니다.
Suffix ds-callout__suffix뒤에 붙는 아이콘이나 요소입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
toneneutral informative positive warning critical magic 은 CSS 만

사용 지침

구분내용
Do앞 아이콘은 채움(Solid) 모양을 씁니다.
Do제목, 본문, 링크는 한 줄로 이어 쓰고, 사이는 두 칸 띄웁니다.
DoBanner는 화면 맨 위에 전체 폭으로, 한 번에 하나만 띄웁니다.
Do본문 안의 안내는 Callout을 씁니다.
Don't전체를 누를 수 있는 Callout에는 링크 글자를 따로 넣지 않습니다.

예시

입력 칸 가까이에 미리 알리기

이 화면에만 해당하는 안내는 본문 안, 관련 입력 칸 바로 위에 Callout으로 둡니다. 제목과 본문은 한 줄로 이어 쓰고 사이는 두 칸 띄웁니다.

배송 안내 제주와 산간 지역은 하루 더 걸려요.

문제가 생긴 곳에서 고칠 방법 알리기

문제가 생긴 정보 바로 위에 critical Callout을 두고 고치는 방법을 링크로 붙입니다. 링크는 문장 끝에 두 칸 띄워 이어 씁니다.

규격

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-callout-bgvar(--ds-color-bg-neutral)
--ds-callout-fgvar(--ds-color-fg-neutral)

크기와 여백

tone: neutral(기본) / informative / positive / warning / critical
Figma: padding x3_5 / gap x2 / min-h50 / shape/md / t04 / 아이콘 Solid 16
  neutral bg/neutral + fg/neutral(info) / informative bg/informative-weak + fg/brand-contrast(info)
  positive bg/positive-weak + fg/positive(circle-check) / warning bg/warning-weak + fg/warning(triangle-alert)
  critical bg/critical-weak + fg/critical(circle-alert)
제목/링크는 본문과 같은 줄(inline), 구분은 띄어쓰기 두 칸. 제목 Bold / 링크 밑줄.
