Image Frame

사용자가 올린 사진을 정해진 비율로 보여 주는 틀

1/5

미리보기

1/5

사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
ratio1:1 4:3 16:9
켜고 끄는 속성stroke indicator

바꿀 수 있는 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-imageframe-ratio1

사용 지침

  • 사진은 Image Frame 비율 안에 채워 넣고, 여러 장을 넘길 때 Carousel 항목으로 넣는다. 터치 화면에서는 넘기기 버튼 없이 손가락으로 넘긴다.

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

ratio: 기본 1:1 / data-ratio="4:3" / data-ratio="16:9" (그 밖은 --ds-imageframe-ratio)   stroke: data-stroke
Figma: shape/sm / 빈 자리 bg/neutral / stroke 안쪽 1px stroke/neutral-subtle
  얹는 표시는 가장자리에서 x1_5 / indicator padding x0_5 x1_5, pill, palette/static-black-alpha-800, Static t01 Medium 흰색
