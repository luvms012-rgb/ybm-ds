사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
Trigger contentplaceholder selected
stateenabled open disabled

사용 지침

  • 여러 개를 고를 때만 Multi Select. 고른 값이 많으면 2개까지 보여 주고 나머지는 +N.

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

Popover 와 같이 data-ds-popover="id" 로 열고, 바깥 누르기와 Esc 로 닫는다.
ybm-ds.js 가 고른 값을 Badge 로 칸에 채우고, data-max(기본 2) 를 넘으면 +N 으로 줄인다.
