사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

부품설명
Node ds-tree__node트리의 항목 하나입니다. 아래 단계를 품을 수 있습니다.
Row ds-tree__row항목 한 줄입니다.
Toggle ds-tree__toggle펼치고 접는 표시입니다.
Icon ds-tree__icon뜻을 빠르게 알려 주는 아이콘입니다.
Label ds-tree__label항목 이름입니다.
Suffix ds-tree__suffix뒤에 붙는 아이콘이나 요소입니다.
Group ds-tree__group아래 단계 항목들을 묶은 영역입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
sizemedium small
guidesnone

그 밖에: aria-expanded, aria-selected

동작

ybm-ds.js를 불러오면 알아서 동작합니다.

  • 줄을 누르면 펼치고 접고 고른다(change, detail.value), 위아래 화살표 이동, 오른쪽 펼침, 왼쪽 접기

사용 지침

구분내용
Do줄마다 알아보기 쉬운 이름과 아이콘을 둡니다.
Do중요한 갈래는 처음부터 펼쳐 둡니다.
Don't4단계보다 깊게 넣지 않습니다.
Don't위아래 관계가 없는 목록에는 쓰지 않습니다. 그때는 List 를 씁니다.

규격

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-tree-row40px
--ds-tree-indent20px

크기와 여백

size: medium(기본) 줄 40, t04 / small 줄 32, t03 / 줄 좌우 x2, 모서리 shape/sm, 아이콘 18
한 단계 들여쓰기 20(펼침 표시 자리 20, 펼칠 것이 없는 줄도 자리를 둔다) / 이음선 stroke/neutral-muted, data-guides="none" 이면 들여쓰기만
고름 aria-selected 또는 aria-current = bg/neutral-weak-alpha + fg/neutral + Medium (Side Navigation 과 같다)
ybm-ds.js: 줄을 누르면 펼치거나 접고 그 항목을 고른다(change, detail.value), 위아래 화살표로 이동, 오른쪽 펼침, 왼쪽 접기
