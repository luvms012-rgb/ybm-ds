Timer

흐른 시간이나 남은 시간을 숫자로 보여 주는 글자

남은 시간 0:00흐른 시간 0초

Preview

남은 시간 0:00 흐른 시간 0초

Usage

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

Properties

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
formatclock elapsed
켜고 끄는 속성data-start data-end

Guidelines

  • 숫자 폭이 고정되어 값이 바뀌어도 흔들리지 않는다. 크기와 색은 자리에 맞춰 바꾸고, 시간이 다 되면 ds-timer-end 이벤트로 다음 동작을 잇는다.

Specification

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

format: 기본 clock(12:34, 1시간 넘으면 1:02:34) / data-format="elapsed"(12분 34초)
흐른 시간: data-start="시작 시각" / 남은 시간: data-end="끝 시각" (ISO 문자열 또는 밀리초)
ybm-ds.js 가 1초마다 글자와 datetime 을 바꾸고, 남은 시간이 0 이 되면 ds-timer-end 이벤트를 한 번 보낸다.
Figma: t02 fg/neutral-muted, 숫자 폭 고정 / 크기와 색은 놓이는 자리에 맞춰 바꿔 쓴다
