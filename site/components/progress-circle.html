Progress Circle

작업이 진행 중임을 알리는 원형 표시입니다.

FigmaCode

Usage

아래 구조를 그대로 복사해 쓰세요. 대괄호 [ ] 안은 필요할 때만 넣습니다.

Properties

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
toneneutral brand staticWhite
typedeterminate indeterminate
켜고 끄는 속성size

CSS Variables

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-progress-value40

Best Practices

GuidancePractices
Don't따로 Spinner 를 두지 않고 Progress Circle 의 indeterminate 를 쓴다.
DostaticWhite 는 어두운 배경과 이미지 위 전용입니다.
Dodeterminate 는 진행률을 실제로 알 수 있을 때만 씁니다. 모르면 indeterminate 입니다.

Specification

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

tone: neutral(기본) / brand / staticWhite   size: 24(기본) / 40 / 56   type: determinate / indeterminate
  indeterminate: data-type="indeterminate" (회전하는 25% 호)
Figma: 두께 24→3 / 40→5 / 56→7 / 둥근 끝 / 12시 시작
  neutral 트랙 palette/gray-200 + 호 palette/gray-500 / brand palette/brand-200 + bg/brand-solid
  staticWhite palette/static-white-alpha-300 + palette/static-white (팔레트 직참은 의도된 예외)
