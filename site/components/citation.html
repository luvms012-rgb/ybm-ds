Citation

70 .ds-citation Figma

미리보기

예시
번호1 출처 이름 출처 이름

사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
typenumber label
켜고 끄는 속성icon

사용 지침

  • AI 답변처럼 서식 있는 글은 Markdown 으로 감싸고, 코드는 Code Block, 근거는 번호나 출처 칩(Citation)으로 단다.

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

type: 기본 label(출처 이름 칩) / data-type="number"(글 뒤 위첨자 번호)
Figma: 높이 x5, t02, fg/neutral-muted / number 최소 폭 x5, 좌우 x1, pill, bg/brand-weak, SemiBold
  label 좌우 x2(아이콘이 있으면 왼쪽 x0_5), gap x1, shape/sm, 1px stroke/neutral-weak, 최대 15em / 아이콘 칸 x4 원, 아이콘 12
