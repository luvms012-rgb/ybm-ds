Citation

본문의 근거가 된 출처를 보여 주는 컴포넌트입니다.

Figma코드
새 창으로 열기
전체 목차 llms.txt

겨울철에는 실내 습도를 40~60%로 맞추면 좋아요.1 건강 정보 포털

사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

구조

한빛일보
부품설명
Icon ds-citation__icon출처 사이트 아이콘입니다.
Label ds-citation__label출처 이름입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
typenumber label
켜고 끄는 속성icon

사용 지침

구분내용
DoAI 답변처럼 서식 있는 글은 Markdown으로 감쌉니다.
Do코드는 Code Block에 넣습니다.
Do근거는 번호나 출처 칩(Citation)으로 붙입니다.

예시

답변 문장 뒤에 번호로 근거 붙이기

AI 답변은 Markdown으로 감싸고, 근거가 된 문장 끝에 번호 Citation을 붙입니다. 번호를 누르면 답변 아래 출처 목록으로 옮겨 가 원문을 확인할 수 있습니다.

받은 지 5일 된 상품도 환불돼요?

네, 상품을 받은 날부터 7일 안이면 환불을 신청할 수 있어요.1 포장을 뜯었더라도 쓰지 않은 상품이면 돼요.2

출처

  1. 교환과 환불 규정
  2. 환불 자주 묻는 질문

출처가 적으면 이름을 칩으로 보여 주기

출처가 한두 곳이면 번호 대신 출처 이름을 칩으로 붙여 어디서 온 내용인지 바로 보여 줍니다. 이름이 길면 칩 안에서 말줄임으로 줄어듭니다.
