Avatar

사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
size20 24 36 42 48 56 64 80 96 108
shapecircle rounded square
status tonepositive neutral critical
group size20~64 × shape

그 밖에: +N

바꿀 수 있는 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-avatar-size36px
--ds-avatar-badge14px
--ds-avatar-radiusvar(--ybm-shape-pill)
--ds-avatar-bgvar(--ybm-color-palette-gray-500)
--ds-avatar-status-sizemax(8px, calc(var(--ds-avatar-size) * 0.26))
--ds-avatar-status-ringclamp(1.5px, calc(var(--ds-avatar-size) * 0.04), 4px)
--ds-avatar-status-colorvar(--ybm-color-bg-positive-solid)
--ds-avatar-group-size36px
--ds-avatar-group-radiusvar(--ybm-shape-pill)
--ds-avatar-group-ringmax(1.5px, calc(var(--ds-avatar-group-size) * 0.05))

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

size : 20 / 24 / 36(기본) / 42 / 48 / 56 / 64 / 80 / 96 / 108
shape: circle(기본) / rounded(크기의 1/4, 곡률 노브 따름) / square
내용 우선순위: 사진 > 이니셜 > 기본 실루엣(사진/이니셜이 없으면 자동)
※ 이니셜은 반드시 .ds-avatar__initials 로 감싼다(맨 글자만 넣으면 실루엣과 겹친다).
※ 사진 로드 실패 시 이니셜로 바꾸는 처리는 개발 영역.
상태 점(.ds-avatar__status) — 색 + 모양을 함께 써서 색만으로 구분하지 않는다 (WCAG 1.4.1)
  positive(기본) 온라인   = 초록 꽉 찬 점
  neutral        자리 비움 = 회색 링
  critical       방해 금지 = 빨강 점 + 흰 가로줄
  지름 = 아바타의 26% (최소 8px) / 배경색 링 / circle 은 4시 방향, rounded/square 는 우하단 모서리
Figma: 원 / 이미지 없을 때 palette/gray-500 / 1px ring stroke/neutral-subtle(INSIDE)
       shape rounded/square 는 badgeMask=none 에만 / status 속성(Avatar Status 인스턴스) / Avatar Group/Group Overflow 세트
       badge 지름 = 24→10 / 36→14 / 42→16 / 48→18 / 56→20 / 64→22 / 80→28 / 96→32 / 108→36 (우하단)
