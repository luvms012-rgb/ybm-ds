Empty

보여 줄 데이터가 없을 때 그 자리를 채우는 안내입니다.

40 .ds-empty Figma

미리보기

예시

아직 접수 내역이 없어요

원하는 시험을 찾아 접수해 보세요.

사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
켜고 끄는 속성size

바꿀 수 있는 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-empty-media56px
--ds-empty-icon28px

사용 지침

  • 제목은 상황을, 설명은 다음 행동을 말합니다. 오류는 Empty 가 아니라 Callout(critical) 이나 Result Section 으로 안내합니다.
  • 버튼은 0~1개가 기본이고 많아도 2개까지입니다.
  • 아이콘은 상황에 맞게 바꿉니다.
  • 카드나 목록 안의 좁은 자리에는 small 을 씁니다.

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

size: medium(기본) / small
Figma medium: padding 40/16 / gap x4 / media 56(아이콘 28) / title t06 Bold / desc t04 / actions 위 x2 / 버튼 medium
      small : padding 24/16 / gap x3 / media 40(아이콘 20) / title t05 Bold / desc t03 / actions 위 x1 / 버튼 small
  media bg/neutral-muted + 아이콘 fg/neutral-subtle / title fg/neutral / desc fg/neutral-subtle / 가운데 정렬
