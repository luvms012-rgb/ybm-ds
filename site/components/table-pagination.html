Table Pagination

표 아래에서 페이지를 넘기고 한 번에 보일 행 수를 바꾸는 컴포넌트입니다.

Figma코드
새 창으로 열기
전체 목차 llms.txt
/ 총 237개

사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

구조

11-20/ 총 237개
부품설명
Size ds-tablepagination__size한 번에 볼 개수를 고르는 영역입니다.
Label ds-tablepagination__label개수 고르기 앞에 붙는 글자입니다.
Select ds-tablepagination__select한 번에 볼 개수를 고르는 Select입니다.
Range ds-tablepagination__range지금 보고 있는 항목 범위입니다.
Position ds-tablepagination__position지금 보고 있는 범위입니다.
Current ds-tablepagination__current지금 페이지 번호입니다.
Total ds-tablepagination__total전체 개수입니다.
Item ds-pagination__item페이지 이동 버튼입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
statedefault unknownTotal empty

그 밖에: 최소 폭 640

사용 지침

구분내용
Do데이터 표 아래에서만 씁니다.
Do일반 목록에는 Pagination을 씁니다.
Do페이지당 줄 수 선택지는 3~4가지로 둡니다.

예시

관리 표 아래에서 페이지와 행 수 고르기

데이터 표 바로 아래에 붙여 페이지와 페이지당 행 수를 함께 바꿉니다. 행 수 선택지는 3가지로 두고, 표와 같은 가로 스크롤 영역 안에 넣어 함께 밀리게 합니다.

규격

크기와 여백

state: default / unknownTotal(전체 개수를 모를 때) / empty(데이터 없음)
empty: 범위 select 에 disabled, 이동 버튼에 aria-disabled="true"
Figma: 최소 폭 640 / padding x2 x4 / 양 끝 정렬 / 한 줄 고정(좁으면 표와 같은 가로 스크롤 영역에 둔다)
  label, total t04 fg/neutral-subtle / select h36 padding 0 8 0 12 gap x1 shape/sm bg/layer-default 1px stroke/neutral-weak
  값 t04 Medium fg/neutral / chevron 16 / disabled bg/disabled fg/disabled / 이동 버튼은 Pagination Item(prev, next)
일반 목록의 페이지 이동은 Pagination 을 쓴다.
