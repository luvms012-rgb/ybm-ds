Select Box

선택지를 설명과 함께 상자로 크게 보여 주는 컴포넌트입니다. 요금제처럼 차이를 읽고 고를 때 씁니다.

Figma코드
새 창으로 열기
전체 목차 llms.txt

사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

구조

부품설명
Texts ds-selectbox__texts제목과 설명을 묶는 글자 영역입니다.
Label ds-selectbox__label이름이나 값을 보여 주는 글자입니다.
Desc ds-selectbox__desc제목에 덧붙이는 설명 글입니다.
Control ds-checkbox__control실제로 값을 입력하거나 고르는 부분입니다.
Control ds-radio__control실제로 값을 입력하거나 고르는 부분입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
typecheck radio
stateunchecked checked disabled
layouthorizontal vertical

사용 지침

구분내용
Do설명이 필요한 선택지가 2~6개일 때 씁니다.
Do짧은 선택지는 Radio Group이나 Checkbox를 씁니다.
Don't한 묶음 안에서 check와 radio를 섞지 않습니다.

예시

설명을 읽고 고르는 이용권

선택지마다 가격과 조건 같은 설명이 필요할 때 Select Box로 크게 보여 줍니다. 짧은 라벨만으로 고를 수 있으면 Radio Group을 씁니다.

이용권

여러 개를 고를 때는 체크로만

관심 분야처럼 여러 개를 고를 때는 모든 상자에 체크 표시를 씁니다. 한 묶음 안에서 check와 radio를 섞으면 몇 개를 골라야 하는지 헷갈립니다.

관심 있는 분야를 모두 골라 주세요

규격

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-selectbox-columns1
--ds-selectbox-linevar(--ds-color-stroke-neutral-weak)
--ds-selectbox-bgvar(--ds-color-bg-layer-default)

크기와 여백

layout: horizontal(기본) / vertical(여러 열로 놓을 때)
표시는 Checkbox(square/neutral/medium), Radio(neutral/medium) 를 그대로 쓴다.
Figma: padding x4 x5 / gap x3 / shape/lg / bg/layer-default / 1px stroke/neutral-weak
  선택 1px stroke/neutral-contrast(색만 진해짐) / disabled bg/disabled + 글자 fg/disabled
  label t05 Medium fg/neutral / desc t04 fg/neutral-subtle / 글 사이 2 / 앞 아이콘 24
