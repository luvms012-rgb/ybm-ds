02 .ds-link Figma

미리보기

예시
아이디 찾기비밀번호 재설정

사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
Figma stateenabled hover

그 밖에: --ds-link-color(-hover)

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.

-------------------------------------------------------------------------- */
.ds-link {
  --ds-link-color: var(--ybm-color-fg-neutral-subtle);
  --ds-link-color-hover: var(--ybm-color-fg-neutral);
  display: inline;
  color: var(--ds-link-color);
  font-size: var(--ybm-font-size-t05);
  line-height: var(--ybm-line-height-t05);
  text-decoration: underline;
  text-underline-offset: 3px;
  transition: color var(--ybm-duration-fast) var(--ybm-easing-standard);
}
.ds-link:hover { color: var(--ds-link-color-hover); }
