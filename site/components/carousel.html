Carousel

가로로 넘기며 보는 묶음입니다.

Figma코드

사용법

아래 구조를 그대로 복사해 쓰세요. 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

그 밖에: 항목 사이 x2, 끝 흐림 x1, 버튼 32

CSS 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-carousel-gapvar(--ybm-space-x2)
--ds-carousel-padding0px
--ds-carousel-fadevar(--ybm-space-x1)
--ds-carousel-fade-startvar(--ds-carousel-fade)
--ds-carousel-fade-endvar(--ds-carousel-fade)

사용 지침

구분내용
Do사진은 Image Frame의 비율 안에 꽉 채워 넣습니다.
Do여러 장을 넘겨 볼 때는 Carousel 항목으로 넣습니다.
Do터치 화면에서는 넘기기 버튼 없이 손가락으로 넘깁니다.

규격

Figma와 CSS가 함께 따르는 크기, 여백, 색입니다.

항목은 넘길 때 시작 위치에 맞춰 멈춘다. 이미지 넘기기 배너는 Image Frame 을 항목으로 넣어 만든다.
ybm-ds.js 가 처음/끝에 닿으면 data-at-start / data-at-end 를 붙여 그쪽 흐림과 버튼을 감추고, 버튼을 누르면 한 화면씩 넘긴다.
Figma: 항목 사이 x2 / 양 끝 흐림 x1 / Carousel Button 32 pill, bg/layer-floating, elevation overlay, 아이콘 16, 가장자리에서 x2
