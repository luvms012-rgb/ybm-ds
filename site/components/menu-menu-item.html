사용법

아래 구조를 그대로 쓰고, 대괄호 [ ] 안은 필요할 때만 넣습니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
tonecritical

바꿀 수 있는 변수

서비스에서 모양을 바꿀 때는 이 변수만 덮어씁니다.

변수기본값
--ds-menu-item-fgvar(--ybm-color-fg-neutral)

사용 지침

  • 동작 실행은 Menu, 값 고르기는 Select.
  • 값을 고르는 자리가 아닙니다. 폼에 제출할 값 고르기는 Select, 동작 실행이 Menu 입니다.
  • 아이콘은 전체 항목에 쓰거나 전부 쓰지 않습니다. 일부 항목에만 넣지 마세요.
  • 라벨 없이 아이콘만 두지 않습니다.
  • 삭제, 차단 같은 되돌릴 수 없는 항목은 critical tone 으로 두고 목록 끝에 divider 로 분리합니다.
  • 라벨은 2~6자 동사형으로 쓰고, 한 메뉴 안에서 어조와 형식을 통일합니다.
  • 설명은 필요한 항목에만 1줄 이내로 답니다.

디자인 값

Figma 와 CSS 가 함께 따르는 크기, 여백, 색입니다.
