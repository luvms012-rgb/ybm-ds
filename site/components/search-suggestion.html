Search Suggestion

검색어를 입력하는 동안 추천 검색어를 보여 주는 컴포넌트입니다.

Figma코드
새 창으로 열기
전체 목차 llms.txt
  • 운동화 추천
  • 운동화 세탁
  • 러닝 운동화

사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

구조

최근 검색어
  • 회의록보조 설명

검색 결과가 없어요

부품설명
Icon ds-input__icon뜻을 빠르게 알려 주는 아이콘입니다.
Control ds-input__control실제로 값을 입력하거나 고르는 부분입니다.
Clear ds-input__clear입력한 값을 지우는 버튼입니다.
Heading ds-search-suggest__heading목록 위에 붙는 소제목입니다.
List ds-search-suggest__list항목 목록입니다.
Item ds-search-suggest__item목록의 항목 하나입니다.
Content ds-search-suggest__content주된 내용이 들어가는 영역입니다.
Label ds-search-suggest__label이름이나 값을 보여 주는 글자입니다.
Desc ds-search-suggest__desc제목에 덧붙이는 설명 글입니다.
Empty ds-search-suggest__empty결과가 없을 때 보이는 글입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
contentsuggestion recent empty
Item stateenabled highlighted
켜고 끄는 속성description

동작

ybm-ds.js를 불러오면 알아서 동작합니다.

  • 입력 칸(role=combobox, aria-controls)에서 위아래 화살표로 줄 고르기, Enter 로 그 줄 누르기

사용 지침

구분내용
Do검색 칸은 Text Field outline에 search 아이콘과 지우기 버튼을 붙여 만듭니다.
Do검색 칸에는 type="search"와 role="combobox"를 붙입니다.
Do입력 전에는 최근 검색어, 입력 중에는 추천어, 결과가 없으면 안내 문구를 보여 줍니다.

예시

입력하기 전에는 최근 검색어 보여 주기

검색 칸을 눌렀지만 아직 입력하지 않았으면 머리말과 함께 최근 검색어를 보여 줍니다. 앞에 clock 아이콘을 두어 추천어와 구별합니다.

최근 검색어
  • 영어 회화
  • 모의고사
  • 환불 규정

인기 강의

  • 영어 회화 기초강의 24개
  • 컴퓨터 활용 실무강의 30개
  • 비즈니스 이메일 쓰기강의 16개

입력하는 동안에는 추천어 보여 주기

글자를 입력하는 동안에는 search 아이콘을 단 추천어를 보여 줍니다. 강의 수처럼 고르는 데 도움이 되는 정보는 보조 설명으로 붙입니다.

  • 영어 회화강의 24개
  • 영어 문법강의 18개
  • 비즈니스 영어강의 9개

인기 강의

  • 영어 회화 기초강의 24개
  • 컴퓨터 활용 실무강의 30개
  • 비즈니스 이메일 쓰기강의 16개

찾은 것이 없으면 안내 문구 보여 주기

맞는 추천어가 없으면 빈 칸 대신 ds-search-suggest__empty 문구를 보여 줍니다. 아무것도 뜨지 않으면 검색이 멈춘 것처럼 보입니다.

검색 결과가 없어요

인기 강의

  • 영어 회화 기초강의 24개
  • 컴퓨터 활용 실무강의 30개
  • 비즈니스 이메일 쓰기강의 16개

규격

크기와 여백

검색 입력 칸은 Text Field(04) outline 에 search 아이콘과 지우기 버튼을 붙여 쓴다.
입력 전 최근 검색어(머리말 + clock), 입력 중 추천어(search), 찾은 것이 없으면 empty 문구.
열고 닫기와 목록 채우기는 서비스가 한다. ybm-ds.js 는 입력 칸의 위아래 화살표로 줄 고르기와 Enter 만 맡는다.
Figma: padding x1 / shape/lg / bg/layer-floating / elevation overlay / 최대 높이 300 / 입력 칸과 같은 폭
  머리말 padding x2 x2 x1, t02 fg/neutral-muted / empty padding x3, t02 fg/neutral-muted, 가운데
  Search Suggestion Item padding x2, gap x2, shape/sm, 아이콘 16 fg/neutral-subtle, 글자 t04 fg/neutral, 설명 t02 fg/neutral-muted
  highlighted bg/transparent-pressed
