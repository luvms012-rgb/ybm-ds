Snackbar

작업 결과를 화면 아래에 잠깐 띄워 알려 주는 컴포넌트입니다.

Figma코드
새 창으로 열기
전체 목차 llms.txt
장바구니에 담았어요

사용법

아래 구조를 복사해 씁니다. 대괄호 [ ] 안은 필요할 때만 넣습니다.

구조

저장했어요
부품설명
Message ds-snackbar__message알릴 내용을 담은 글입니다.
Action ds-snackbar__action바로 실행하는 작은 버튼입니다.

속성

Figma 속성 이름을 그대로 data-* 속성으로 씁니다.

속성값
variantdefault positive critical

동작

ybm-ds.js를 불러오면 알아서 동작합니다.

  • DS.snackbar("문구", { variant: "positive"|"critical", action: "확인", onAction, duration })

사용 지침

구분내용
Do4초 동안 보이고, 한 번에 하나만 띄웁니다.

예시

저장한 결과를 짧게 알리기

저장 버튼을 누르면 화면 아래에 결과를 한 줄로 알립니다. 4초 뒤 저절로 사라지므로 사용자가 닫지 않아도 되는 알림에 씁니다.

게시판과 댓글에 보이는 이름이에요.

지운 직후 되돌릴 기회 주기

알림을 지우면 되돌리기 버튼 하나를 붙여 알립니다. 확인 창으로 흐름을 막지 않으면서 실수를 바로잡을 길을 남길 때 씁니다.

  • 주문한 상품이 출발했어요 오늘 오전 9:12
  • 할인 쿠폰이 3일 뒤 사라져요 어제 오후 6:30
  • 1:1 문의에 답변이 달렸어요 11월 2일

실패하면 다시 시도하게 하기

요청이 실패하면 critical 아이콘과 다시 시도 버튼을 함께 띄웁니다. 문구에는 왜 안 됐는지를 짧게 적고 버튼으로 바로 다시 하게 합니다.

신규 회원 10% 할인 쿠폰

11월 30일까지 쓸 수 있어요.

규격

크기와 여백

variant: default / positive / critical
Figma: padding x2_5(+본문 좌우 x1_5) / min-h44 / max-w560 / shape/sm / bg/neutral-solid / elevation overlay
       message t04 fg/on-neutral-solid / action t04 Bold / gap x2_5 / 아이콘 Solid 24
       positive 아이콘 bg/positive-solid / critical 아이콘 bg/critical-solid
