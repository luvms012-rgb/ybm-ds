# Radius

모서리는 요소의 둥글기를 정해 화면의 인상을 맞춥니다.

## 개요

모서리는 쓰임 이름으로 씁니다. 어떤 영역에 `--ybm-shape-scale`을 0과 1 사이 값으로 덮어쓰면 그 안의 모서리만 덜 둥글게 바꿀 수 있습니다.

## 토큰

| 토큰 | 값 | 보기 |
| --- | --- | --- |
| `--ybm-shape-2xs` | 4px |  |
| `--ybm-shape-xs` | 6px |  |
| `--ybm-shape-sm` | 8px |  |
| `--ybm-shape-md` | 10px |  |
| `--ybm-shape-lg` | 12px |  |
| `--ybm-shape-xl` | 16px |  |
| `--ybm-shape-2xl` | 20px |  |
| `--ybm-shape-3xl` | 24px |  |
| `--ybm-shape-pill` | 9999px |  |
