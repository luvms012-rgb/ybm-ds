Iconography

화면에 쓰는 작은 그림입니다. 클래스 하나만 붙이면 되고, 색과 크기는 글자를 따라갑니다.

FigmaCode

Overview

아이콘은 Lucide 한 가지만 씁니다. 지금 바로 쓸 수 있는 아이콘은 62개예요. 더 필요하면 아래 Add an Icon 에서 찾아 넣습니다.

완료
  • 색은 따로 정하지 않습니다. 둘러싼 글자색을 그대로 따라가요.
  • 크기는 기본 20 이고, ds-icon--sm 16, ds-icon--lg 24 두 가지가 더 있어요.
  • 아이콘만 있는 버튼에는 aria-label 로 뜻을 적습니다. 글자 옆의 꾸밈용 아이콘은 aria-hidden="true".

Icons

이름을 누르면 클래스가 복사됩니다. 이름 끝에 -solid 가 붙은 것은 채움 모양이에요.

Size and Color

크기는 셋 중 하나를 고릅니다. 그 밖의 크기가 꼭 필요하면 --ds-icon-size 변수로 바꿉니다. 색은 부모의 글자색을 바꾸면 따라옵니다.

Add an Icon

여기 없는 아이콘은 Lucide 1,999개에서 찾습니다. 아이콘을 누르면 icons.css 에 붙여 넣을 줄이 복사되고, 붙여 넣으면 바로 쓸 수 있어요. 이미 들어 있는 것은 CSS 표시가 붙어 있고 누르면 클래스가 복사됩니다.

Best Practices

GuidancePractices
Do같은 뜻에는 늘 같은 아이콘을 씁니다. 닫기는 x, 더 보기는 ellipsis.
Do아이콘만 있는 버튼에는 aria-label 을 붙입니다.
Do색은 글자색을 따라가게 둡니다. 상태 색이 필요하면 부모 글자색을 바꿉니다.
Do크기는 16, 20, 24 셋 중에서 고릅니다.
Don't이모지나 다른 아이콘 세트를 섞지 않습니다.
Don't아이콘 그림을 손으로 고치지 않습니다. Lucide 원본 그대로 씁니다.
Don't아이콘 하나로 긴 뜻을 대신하지 않습니다. 뜻이 분명하지 않으면 글자를 같이 씁니다.
