Iconography

UI 아이콘은 Lucide 한 가지만 씁니다. Lucide 전체 1,999개 가운데 CSS 로 바로 쓸 수 있는 것은 54개이고, 나머지는 필요할 때 icons.css 에 한 줄 넣어 씁니다.

Usage

  • 색은 부모 글자색을 따릅니다. 크기는 --ds-icon-size 로도 바꿀 수 있어요.
  • 이름 끝에 -solid 가 붙은 것은 채움 모양입니다.
  • 뜻이 있는 아이콘만 쓰는 버튼에는 aria-label 을 꼭 답니다. 꾸밈용 아이콘은 aria-hidden="true".
  • 필요한 아이콘이 없으면 Lucide 원본 그대로 icons.css 에 한 줄 추가합니다.

CSS Icons

누르면 클래스 이름이 복사됩니다.

All Lucide Icons

Lucide 1.64.0 의 아이콘 1,999개입니다. CSS 표시가 붙은 것은 누르면 클래스 이름이, 나머지는 icons.css 에 넣을 줄이 복사됩니다. 위 찾기 칸에 영어 이름이나 뜻을 넣으면 두 목록이 함께 걸러집니다.
