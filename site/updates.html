Updates

yds 업데이트 소식과 변경 기록입니다.

v1.1.0 2026. 11. 4

확인할 변경

  • DS Card subtle, inset List, Popover 테두리 색과 Divider 색이 바뀌어 화면의 선이 달라 보일 수 있습니다.

바뀐 것

  • DS 선 색을 두 가지로 맞췄습니다. 바깥 테두리는 모두 stroke/neutral-weak, 안쪽 구분선은 모두 stroke/neutral-muted입니다. Card subtle도 기본과 같은 테두리입니다.
  • DS Checkbox, Radio 테두리를 진하게 바꿨습니다.

새 기능

  • DS Accordion을 열고 닫을 때 높이가 부드럽게 바뀝니다.

고친 것

  • DS Avatar 상태 점이 납작해 보이던 것을 고쳤습니다.
  • DS 제목 옆 Badge를 글자 가운데에 맞췄습니다.

v1.0.0 2026. 11. 4

새 기능

  • 사이트 Foundations에 화면 폭 기준을 모은 Breakpoint 페이지를 더했습니다.
  • 사이트 컴포넌트 71개에 실제 화면 속 사용 예시를 2 ~ 3개씩 넣었습니다. 예시마다 이름, 쓰임 설명, 미리보기, 코드가 있습니다.
  • 사이트 코드 상자에 글자 색을 입혔습니다.
  • DS Carousel에 넘겨도 제자리에 있는 번호(ds-carousel__count)를 더했습니다.
  • 사이트 AI 도구용 규칙 파일(AGENTS.md, CLAUDE.md, yds.mdc), 아이콘 목록(icons.json), 규칙 검사 스크립트(yds-check.mjs)를 더했습니다.
  • DS 버전을 v1.0.0부터 매깁니다. 운영 서비스는 버전을 고정한 주소를 쓰고, 새 버전은 Updates를 확인한 뒤 올립니다.
  • DS GitHub에 올릴 때마다 DS, 사이트, 템플릿, 마크다운이 서로 맞는지 자동으로 검사합니다.

바뀐 것

  • DS 이름을 YBM DS에서 yds로 바꿨습니다.
  • DS Segmented Control 글자를 Medium으로, 고른 칸은 SemiBold로 바꿨습니다.
  • DS List Item, Accordion 제목을 SemiBold로 바꿔 설명과 위계를 나눴습니다.
  • DS Dialog 아래쪽 버튼 둘은 가로로 나누고, 버튼이 없는 창도 아래 여백을 둡니다.
  • DS Avatar 바탕을 연하게, 메뉴 항목 모서리를 덜 둥글게, Bottom Navigation 위 여백을 넓혔습니다.
  • DS 토큰 이름을 --ybm-*에서 --ds-*로, CSS 레이어를 ds.*로, 스크립트를 DS로 바꿨습니다. 예전 이름도 compat-ybm.css와 window.YBM으로 그대로 쓸 수 있습니다.
  • 사이트 Get Started를 운영 중인 사이트에 DS를 옮기는 다섯 단계와 새로 만들기로 바꿨습니다. 다섯 단계는 살펴보기, 넣기, 브랜드 컬러, 화면 하나씩, 점검입니다. 요청 글은 모두 세 줄이고, 지켜야 할 규칙과 옮길 때 규칙은 llms.txt에 모았습니다.
  • 사이트 AI & Tools를 Get Started에 합쳤습니다.
  • 사이트 글자 위계와 본문 폭을 seed 문서 사이트에 맞췄습니다.
  • DS Date Picker가 320보다 좁은 화면에서는 함께 줄어듭니다.

자세한 변경 기록은 GitHub에 있습니다.
