Updates

YBM DS 업데이트 소식과 변경 기록입니다.

2026. 11. 4

새 기능

  • 사이트 Foundations 에 화면 폭 기준을 모은 Breakpoint 페이지를 더했습니다.

바뀐 것

  • DS 토큰 이름을 --ybm-* 에서 --ds-* 로, CSS 레이어를 ds.* 로, 스크립트를 DS 로 바꿨습니다. 예전 이름은 compat-ybm.css 와 window.YBM 으로 계속 동작합니다.
  • 사이트 Get Started 를 짧은 AI 요청 글 두 개와 직접 시작 두 단계로 줄였습니다. AI 가 지킬 규칙은 llms.txt 에 모았습니다.
  • 사이트 글자 위계와 본문 폭을 seed 문서 사이트에 맞췄습니다.

2026. 11. 3

새 기능

  • 사이트 메뉴를 Get Started, Foundations, Components, Templates, Updates 다섯 개로 나눴습니다.
  • 사이트 Color 를 Overview, Roles, Palette 로, Iconography 를 Overview, Library 로 나누고 아이콘을 찾아 바로 복사하는 라이브러리를 만들었습니다.
  • 사이트 컴포넌트마다 부품 이름과 화살표로 생김새를 보여 주는 구조 그림을 넣었습니다.

바뀐 것

  • DS Table 의 위 선, 머리줄, 행 높이를 다시 정하고 두 줄 칸과 묶음 행을 더했습니다.
  • DS Text Link small, Segmented 높이 32 와 40, Card subtle 선택지를 더했습니다.
  • 사이트 컴포넌트 상세를 사용법, 구조, 속성, 동작, 사용 지침, 예시, 규격 순서로 정리했습니다.

2026. 11. 2

새 기능

  • 템플릿 대시보드, 표, 폼, 커뮤니티, 요금제처럼 자주 만드는 화면을 더해 템플릿이 67종이 되었습니다. 템플릿마다 Figma 화면이 함께 있습니다.

2026. 11. 1

새 기능

  • DS 폴더, 필터, 메일, 설정처럼 화면에 자주 쓰는 Lucide 아이콘 93개를 더했습니다.

2026. 10. 31

새 기능

  • 사이트 컴포넌트와 Foundations 문서마다 Figma 와 코드로 가는 버튼을 달았습니다. Figma 문서 프레임에서도 사이트의 같은 페이지로 갑니다.

2026. 10. 30

새 컴포넌트

  • DS 별점을 보여 주고 고르는 Rating 을 CSS 와 Figma 에 함께 만들었습니다.

2026. 10. 29

새 컴포넌트

  • DS Top App Bar, Top Navigation, Search Suggestion, File Attach, Menu Sheet, Side Panel, Carousel, Code Block 등 16종을 CSS 와 Figma 에 함께 만들었습니다.
