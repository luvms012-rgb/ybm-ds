Updates

YBM DS 업데이트 소식과 변경 기록입니다.

Release Notes

2026. 11. 3

문서 사이트를 다섯 메뉴로

메뉴를 Get Started, Foundations, Components, Templates, Updates 다섯 개로 나눴습니다. Color 는 Overview, Roles, Palette 로, Iconography 는 Overview, Library 로 나누고 아이콘을 찾아 바로 복사하는 라이브러리를 만들었습니다.

2026. 11. 3

컴포넌트 구조 그림

컴포넌트마다 부품 이름과 화살표로 생김새를 보여 주는 구조 그림을 넣었습니다. 화살표는 곧게 부품을 가리키고 서로 엇갈리지 않습니다.

2026. 11. 3

DS Table 개편과 새 선택지

표의 위 선, 머리줄, 행 높이를 다시 정하고 두 줄 칸과 묶음 행을 더했습니다. Text Link small, Segmented 높이 32 와 40, Card subtle 같은 선택지도 늘었습니다.

2026. 11. 2

템플릿 67종

대시보드, 표, 폼, 커뮤니티, 요금제처럼 자주 만드는 화면을 템플릿으로 더해 67종이 되었습니다. 템플릿마다 Figma 화면이 함께 있습니다.

2026. 11. 1

아이콘 93개 추가

폴더, 필터, 메일, 설정처럼 화면에 자주 쓰는 Lucide 아이콘 93개를 더했습니다.

2026. 10. 31

Figma 와 문서 연결

컴포넌트와 Foundations 문서마다 Figma 와 코드로 가는 버튼을 달았습니다. Figma 문서 프레임에서도 사이트의 같은 페이지로 갑니다.

2026. 10. 30

Rating 컴포넌트

별점을 보여 주고 고르는 Rating 을 CSS 와 Figma 에 함께 만들었습니다.

2026. 10. 29

새 컴포넌트 16종

Top App Bar, Top Navigation, Search Suggestion, File Attach, Menu Sheet, Side Panel, Carousel, Code Block 같은 컴포넌트를 CSS 와 Figma 에 함께 만들었습니다.

자세한 변경 기록은 GitHub에 있습니다.
