비교 표

필터 표

묶음 표

미리보기Figma에서 열기

받은함 표

검색 표

청구서 한 건의 정보 아래에 항목 표를 둔 화면입니다. 검색, 보기 전환, 열별 필터로 항목을 좁혀 봅니다.

미리보기Figma에서 열기

트리 표

장바구니, 배송, 결제, 확인을 단계별로 나눈 결제 화면입니다. 오른쪽 요약은 선택에 따라 다시 계산되고, 좁은 화면에서는 아래로 내려갑니다.

미리보기Figma에서 열기

문의 폼

입력란, 선택 칩, 고르기, 긴 글 입력을 한 흐름에 담은 문의 폼입니다. 단계 없이 맨 아래 보내기 버튼 하나로 끝납니다.

단계 폼

한 단계에 한 화면씩 넘어가는 단계별 입력 폼입니다. 진행 단계를 위에 가로로 보여 주고 아래 버튼 줄은 고정합니다.

코드 편집기

칸마다 크기를 바꾸고 접을 수 있는 코드 편집 화면입니다. 파일 목록, 탭으로 여는 문서, 아래 터미널, 맨 아래 상태 막대로 이뤄집니다.

페이지 편집기

문서 목록

디자인 문서

설명 사이에 실제로 동작하는 예시를 넣은 디자인 문서입니다. 미리 보기, 속성 표, Do와 Don't 비교, 복사할 수 있는 코드가 이어집니다.

기술 문서

주문 상세
