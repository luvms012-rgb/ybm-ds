Templates

자주 쓰는 화면을 DS 부품으로 미리 조립해 두었습니다. 통째로 복사해 출발점으로 쓰세요.

Analytics Dashboard

위에서부터 활성 사용자 그래프, 핵심 숫자 타일, 사용자 구성, 참여 표 순서로 넓게 훑어보는 기본 분석 화면입니다.

Preview

Data Dashboard

위쪽 필터 막대를 둔 비교 분석 화면입니다. 지표 타일마다 작은 추이 선과 전일·전주·전월·전년 대비 변화를 함께 보여 줘요.

Preview

Executive Summary Dashboard

리포트처럼 읽는 대시보드입니다. 스코어카드, 목표 달성 막대, 추이 그래프 옆에 무엇이 왜 바뀌었는지 글로 정리한 오른쪽 패널을 둡니다.

Preview

Funnel & Cohort Dashboard

단계별로 얼마나 빠져나가는지 보는 퍼널과, 가입 주별로 얼마나 남아 있는지 보는 잔존 코호트 표를 한 화면에 둔 분석입니다.

Preview

Portfolio Dashboard

시간에 따라 값이 어떻게 바뀌는지 보는 화면입니다. 잔액과 변화 타일, 구성 비율이 쌓인 면적 그래프, 많이 가진 항목 목록과 시장 표로 이어져요.

Preview

Project Status Dashboard

오늘 표시선이 있는 일정 막대, 완료 비율 도넛, 담당자별 진행 표로 프로젝트가 어디까지 왔는지 보는 화면입니다.

Preview

Service Monitoring Dashboard

늘 켜 두는 상태 화면입니다. 상태 색이 있는 타일과 시간 그래프, 서비스별 90일 가동 막대, 오른쪽에 따로 스크롤되는 알림 패널이 있어요.

Preview

Collapsible Table

열이 서로 다른 표 여러 개를 접히는 카드에 하나씩 담은 화면입니다. 묶음마다 칸이 달라 표 하나로 합치면 빈칸이 많아질 때 써요.

Preview

Comparison Table

비교할 대상을 열에, 기준을 묶음 행에 두고 왼쪽 이름 열을 고정한 표입니다. 열마다 대상을 바꿔 고를 수 있고 가장 좋은 값을 강조해요.

Preview

Filterable Table

걸러 보기를 중심에 둔 표입니다. 검색과 여러 필터, 고급 검색, 필터 묶음을 저장하는 보기, 지점별로 묶은 행이 있어요.

Preview

Grouped Table

행을 상태별로 접히는 묶음에 나누고 묶음마다 개수를 붙인 표입니다. 긴 목록을 몇 덩어리로 줄여 읽을 수 있어요.

Preview

Inbox Table

왼쪽 표가 오른쪽 읽기 창의 목차가 되는 두 칸 받은함입니다. 가운데 손잡이로 크기를 바꾸고, 좁아지면 위아래로 쌓여요.

Preview

Searchable Table

청구서 같은 한 건의 정보 아래에 같은 모양의 행을 두고, 검색칸·방식 전환·열별 필터 세 가지로 동시에 좁히는 표입니다.

Preview

Tree Table

부모 행이 자식 행을 품는 계층 표입니다. 코드 저장소처럼 폴더를 펼쳐 내려가고, 옆 패널에 저장소 정보를 둡니다.

Preview

Checkout Form

긴 결제 폼 옆에 주문 요약을 고정해 두는 화면입니다. 입력이 바뀌면 요약이 다시 계산되고, 마지막에 합계를 확인하고 결제해요.

Preview

Checkout Wizard

장바구니, 배송, 결제, 확인을 단계로 나눈 결제 화면입니다. 답이 바뀔 때마다 오른쪽 요약이 다시 계산되고, 좁은 화면에서는 요약이 아래로 내려가요.

Preview

Contact Form

글칸, 알약 버튼, 고르기, 긴 글을 섞은 한 줄 폼입니다. 단계도 갈림도 요약도 없이 맨 아래 전체 폭 보내기 버튼 하나로 끝나요.

Preview

Dialog Wizard

아래 화면은 그대로 둔 채 대화상자 안에서 짧은 단계를 밟는 폼입니다. 작은 단계 표시와 아래쪽에 고정된 버튼 줄이 있어요.

Preview

Form Wizard

한 번에 한 칸씩 넘어가는 여러 단계 폼입니다. 진행 표시를 위쪽 가로로 두어 모든 단계가 전체 폭을 쓰고, 아래 버튼 줄은 고정돼요.

Preview

Inline Wizard

모든 단계를 한 줄로 쌓은 아코디언 단계 폼입니다. 지금 단계만 펼쳐지고, 끝난 단계는 결과와 고치기 버튼만 남긴 한 줄로 접혀요.

Preview

Two-column Form

큰 제목 아래를 두 칸으로 나눈 폼입니다. 한쪽에 내 정보, 다른 쪽에 문의 내용을 두고 맨 아래 연락처 줄로 마무리해요.

Preview

Vertical Wizard

단계를 왼쪽 세로 막대에 고정하고, 오른쪽 패널의 도움말이 지금 고른 칸을 따라 바뀌는 여러 단계 폼입니다. 칸이 많은 긴 입력에 맞아요.

Preview

Settings Dialog

보던 화면을 떠나지 않고 대화상자 안에서 바꾸는 설정입니다. 왼쪽에 찾기와 묶음 메뉴, 오른쪽에 묶인 항목과 바로 반영되는 입력이 있어요.

Preview

Settings Form

설정을 한 장의 긴 폼으로 이어 붙인 가장 단순한 모양입니다. 묶음 사이를 오가는 메뉴 없이 아래로 내리면 모든 설정에 닿아요.

Preview

Settings Panels

왼쪽에 늘 보이는 메뉴로 옆 칸을 바꾸는 설정입니다. 따로 폼을 열지 않고 줄마다 그 자리에서 고쳐요.

Preview

Login Card

가운데 떠 있는 카드 안에 로그인 칸을 두고, 구분선 아래에 다른 서비스로 로그인 버튼, 맨 아래 가입과 약관 링크를 둔 화면입니다.

Preview

Login Split

카드를 반으로 나눠 한쪽에 로그인 폼, 다른 쪽에 꽉 찬 사진을 둔 화면입니다. 칸은 카드형과 같고 사진으로 브랜드 느낌을 더해요.

Preview

Login SSO

입력한 이메일 도메인으로 회사 로그인을 찾아 넘겨 주고, 안 되면 비밀번호로 들어가는 두 단계 로그인입니다.

Preview
