YBM DS란 무엇인가요?

용어뜻
토큰색, 크기, 간격 같은 값에 붙인 이름입니다.
컴포넌트버튼, 입력창처럼 화면을 이루는 부품입니다.
템플릿부품을 조립해 둔 화면 한 장입니다.

시스템 이해하기

Foundations색, 글자, 간격 같은 기본 토큰. Components화면을 이루는 부품의 모양과 쓰임. Templates가져다 고쳐 쓰는 완성 화면.

바로 써 보기

AI 코딩 도구로 만들 때는 AI & Tools의 요청 글을 붙여 넣으면 아래 설치와 규칙을 알아서 맞춥니다.

1. DS 불러오기

<head>에 두 줄을 넣으면 글꼴, 토큰, 아이콘, 컴포넌트가 함께 들어옵니다. ybm-ds.js는 창 열기, 알림처럼 CSS만으로 안 되는 동작을 알아서 맡습니다.

2. 컴포넌트 붙이기

정해진 클래스만 붙이면 됩니다. 쓰는 법은 Components에 있습니다.

상태는 HTML 기본 속성으로 나타냅니다.

상태속성
꺼짐disabled
선택:checked, aria-selected, aria-pressed
지금 위치aria-current="page"
펼침aria-expanded
오류aria-invalid="true"

3. 서비스에 맞게 바꾸기

서비스 CSS는 DS 다음에 불러오고, 컴포넌트 변수(--ds-*)와 시맨틱 색만 덮어씁니다. DS가 CSS 레이어 안에 있어 !important 없이도 서비스 CSS가 이깁니다. 브랜드 색은 Color에서 바꿉니다.

다크 모드

html에 속성 하나를 붙이면 모든 색이 어두운 화면용으로 바뀝니다. 색을 토큰으로만 썼다면 따로 고칠 것이 없습니다.

반응형

작은 화면부터 만들고 폭이 넓어질 때 배치를 바꿉니다. @media 안에서는 CSS 변수를 쓸 수 없어 숫자를 직접 씁니다.

이름폭쓰임
sm480px큰 휴대폰
md768px태블릿, PC 부품으로 바뀌는 기준
lg1280px넓은 PC, 3단 배치
xl1440px아주 넓은 화면
  • Top Navigation ↔ Top App Bar, Side Panel ↔ Bottom Sheet, Dialog ↔ Bottom Sheet는 768을 기준으로 바꿉니다.
  • Side Navigation은 1280 이상 펼침, 768 이상 접힘, 그보다 좁으면 서랍 메뉴입니다.

스크립트 직접 사용

대부분은 HTML 속성만으로 동작합니다. 코드에서 직접 열거나 띄울 때만 아래를 씁니다.

기능사용방법
창 열기, 닫기YBM.openDialog(요소), YBM.closeDialog(요소)
알림 띄우기YBM.snackbar("저장했어요", { variant: "positive" })
새로 고침 끝내기YBM.endRefresh(요소)
나중에 넣은 HTML 연결YBM.init(요소)
