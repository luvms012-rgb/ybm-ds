아래 글을 AI 코딩 도구(ChatGPT, Claude, Cursor 등)에 붙여 넣으면 됩니다.

설치하기

브랜드 컬러 입히기

서비스에 쓸 때 이어서 붙여 넣습니다. 대괄호 안에 브랜드 컬러를 넣습니다.

화면 만들기

대괄호 안만 내 상황에 맞게 바꿉니다.

규칙 점검하기

직접 시작하기

<head>에 두 줄을 넣으면 글꼴, 토큰, 아이콘, 컴포넌트가 함께 들어옵니다. 쓰는 법은 Components에 있습니다.

내 사이트에 적용해보기

운영 중인 사이트는 한 번에 바꾸지 않고 아래 순서대로 적용합니다. 브랜드 컬러와 규칙 점검은 위 AI로 시작하기의 글을 그대로 씁니다.

1. 사이트 살펴보기

아직 고치지 않고, 무엇을 어떤 순서로 바꿀지 먼저 정합니다.

2. DS 넣기

공통 <head>에 넣습니다. 기존 CSS가 DS보다 먼저 적용되어 지금 화면은 거의 그대로입니다.

3. 화면 하나씩 바꾸기

화면마다 대괄호 안만 바꿔 붙여 넣습니다.

다크 모드

html에 속성 하나를 붙이면 모든 색이 어두운 화면용으로 바뀝니다. 색을 토큰으로만 썼다면 따로 고칠 것이 없습니다.

AI가 읽는 파일

주소를 알려 주면 AI가 필요한 것을 골라 읽습니다. 주소를 열지 못하는 도구에는 llms-full.txt를 첨부합니다.

파일내용
llms.txt전체 목차와 지킬 규칙입니다. AI가 여기서 시작합니다.
llms-full.txt모든 문서를 한 파일로 모았습니다.
components.json쓸 수 있는 컴포넌트와 속성 목록입니다.
components.css컴포넌트마다 머리 주석에 HTML 구조가 있습니다.
tokens.css색, 간격, 글자 크기 같은 --ds-* 토큰입니다.
페이지별 .md문서 제목 아래 Markdown 메뉴에서 그 페이지만 복사합니다.

Figma 변수와 CSS 변수는 이름이 같습니다. AI에 Figma 화면을 주면 같은 토큰으로 옮깁니다.
