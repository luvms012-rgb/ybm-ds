AI가 읽는 파일

주소를 알려 주면 AI가 필요한 것을 골라 읽습니다. 주소를 열지 못하는 도구에는 llms-full.txt를 첨부합니다.

파일내용
llms.txt전체 목차와 지킬 규칙입니다. AI가 여기서 시작합니다.
llms-full.txt모든 문서를 한 파일로 모았습니다.
페이지별 .md문서 제목 아래 Markdown 메뉴에서 그 페이지만 복사합니다.
components.json쓸 수 있는 컴포넌트와 속성 목록입니다.
components.css컴포넌트마다 머리 주석에 HTML 구조가 있습니다.
tokens.css색, 간격, 글자 크기 같은 --ds-* 토큰입니다.

Figma 변수 이름이 CSS 변수 이름과 같아, AI에 Figma 화면을 주면 같은 토큰 이름으로 옮깁니다.
