시작하기

YBM DS 를 프로젝트에 넣고 바로 화면을 만들어 보세요.

AI 로 빠르게 시작하기

아래 내용을 AI 코딩 도구(ChatGPT, Claude, Cursor 등)에 붙여 넣으면 설치부터 규칙까지 알아서 맞춰요.

YBM DS 적용하기

그다음 만들고 싶은 화면을 말로 설명하세요. 대괄호 안만 내 상황에 맞게 바꾸면 됩니다. 비슷한 화면이 템플릿 에 있으면 그 화면에서 출발해요.

화면 만들기

이미 만든 화면이 있다면 DS 규칙을 지키는지 점검하게 할 수 있어요.

규칙 점검하기

설치

가장 쉽고 권장하는 방법은 CSS 로 바로 쓰는 것입니다. 빌드 도구나 설치 과정 없이 <head> 에 두 줄만 넣으면 글꼴(Pretendard), 토큰, 아이콘, 컴포넌트가 한 번에 들어와요.

첫 컴포넌트 넣기

정해진 클래스와 속성만 붙이면 됩니다. 각 컴포넌트의 구조와 속성은 Components 에 있어요.

예시

다크 모드

html 요소에 속성 하나만 붙이면 모든 색이 어두운 화면용으로 바뀝니다. 오른쪽 위 달 모양 버튼으로 이 사이트에서도 바로 볼 수 있어요.

모양 바꾸기

서비스 CSS 는 DS 다음에 불러오고, 새 클래스를 만들지 말고 컴포넌트 변수(--ds-*)만 덮어씁니다. 자세한 내용은 사용 규칙 에 있어요.

다른 설치 방법

개발자가 버전을 고정하거나 파일을 직접 가지고 있어야 할 때 씁니다.

버전 고정 주소

위 주소는 늘 최신 버전을 줍니다. 배포 후 바뀌지 않게 하려면 공개 CDN 주소에 커밋 번호를 넣어 고정하세요.

파일 내려받기

저장소를 내려받아 dist 폴더를 프로젝트에 넣고 상대 경로로 불러옵니다. 인터넷이 막힌 환경이나 사내 서버에 둘 때 씁니다.

Tailwind CSS 와 함께

Tailwind 를 쓰는 프로젝트는 토큰을 Tailwind 이름으로 바로 쓸 수 있는 설정 파일이 있어요. 값은 모두 DS 의 CSS 변수를 가리키므로 ybm-ds.css 도 함께 불러와야 합니다.
